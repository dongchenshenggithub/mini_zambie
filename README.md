# 僵尸生存 Roguelike

> 公元3077年，C国某城市发生僵尸疫情，城市封锁，幸存者建立生存点对抗僵尸。

## 简介

一款基于 **Godot Engine** 的俯视视角 Roguelike 射击游戏。

- **6个独特角色** — 每个角色有完全不同的武器加成、回血方式和特殊能力
- **17+种武器** — 远程、近战、激光、喷射、召唤五大类
- **12+种僵尸** — 含飞行单位、远程投掷、精英、Boss
- **15关随机地图** — 城市街道、超市、酒店、医院、停车场
- **装备/饰品/义肢系统** — 深度Build构建
- **灵魂球掉落** — 击杀僵尸获得，升级时购买装备

## 角色一览

| 角色 | 定位 | 核心机制 |
|------|------|----------|
| 退伍老兵昊京 | 全能均衡 | 所有武器+10%，自愈，2随从 |
| 机械武僧 | 近战爆发 | 重型武器+20%，拆武回血，全身义肢 |
| 赛博修仙者 | 飞剑操控 | 近战远程投掷回收，无视障碍 |
| 猫咖店员 | 召唤流 | 5种战斗随从，随从可装备 |
| 大学教授 | 激光专精 | 激光+100%，固定炮台+治疗塔 |
| 外星射手 | 玻璃大炮 | 4条触手握持4把武器，吞噬尸块回血 |

## 快速开始

### 前置要求

- Godot Engine 4.3+（Forward Plus渲染器）

### 运行项目

```bash
# 使用 Godot 编辑器打开项目
godot --editor

# 或直接运行
godot --path .
```

### 操作说明

| 按键 | 功能 |
|------|------|
| W/A/S/D | 移动 |
| 空格 | 攻击（自动射击） |
| E | 使用物品 |

## 项目结构

```
games/
├── project.godot            # Godot项目配置
├── GDD.md                   # 游戏设计文档
├── README.md                # 本文件
├── scripts/                 # GDScript脚本
│   ├── core/                # 核心系统（枚举、状态、义肢）
│   ├── entities/            # 实体（玩家、僵尸、召唤物）
│   ├── weapons/             # 武器（17种武器子类）
│   ├── projectiles/         # 投射物
│   ├── items/               # 道具（药水、配件）
│   ├── map/                 # 地图生成
│   ├── systems/             # 系统（升级、波次、商店）
│   ├── ui/                  # UI组件
│   └── menus/               # 菜单（主菜单、角色选择）
├── scenes/                  # 场景文件
├── assets/                  # 美术资源
└── resources/               # 数据资源
```

## 核心玩法循环

```
选择角色 → 进入随机地图 → 击杀僵尸 → 获得灵魂球/掉落
    ↓
升级 → 选择属性强化 / 用灵魂球购买装备
    ↓
清理区域 → 进入下一关（每3关出现商店）
    ↓
第15关 Boss战 → 通关解锁专属奖励
```
